Apps Script'e anahtar kontrolü nasıl eklenir?
Script düzenleyicide Proje Ayarları → Komut dosyası özellikleri'ne KEY adında bir özellik ekleyip değerine aynı anahtarı yazın. Sonra doGet ve doPost'un en başına şu kontrolü ekleyin ve yeniden dağıtın:
function anahtarOk_(k){ return k === PropertiesService.getScriptProperties().getProperty('KEY'); } // doGet(e) başına: if(!anahtarOk_(e.parameter.key)) return ContentService .createTextOutput(JSON.stringify({ok:false,error:'yetkisiz'})) .setMimeType(ContentService.MimeType.JSON); // doPost(e) başına: var body = JSON.parse(e.postData.contents); if(!anahtarOk_(body.key)) return ContentService .createTextOutput(JSON.stringify({ok:false,error:'yetkisiz'})) .setMimeType(ContentService.MimeType.JSON);
